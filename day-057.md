# Day 57: Serve an ML Model with Flask

# Instructions

The xFusionCorp Industries ML platform team serves the fraud-detection model over HTTP with a Flask app so downstream services can score transactions synchronously. A draft app.py at /root/code/serving/ loads the pre-trained model and declares /health + /predict, but the server binds to the wrong port and the /predict handler is left unimplemented. Your task is to author the /predict handler and bind the server to the exposed port, start the server, and confirm two distinct payloads produce two distinct responses.


Flask is installed at startup (it is not part of the lab image by default).

The project layout under /root/code/serving/:

    - model.pkl – Deterministic RandomForest trained at startup on the shared amount / hour / num_tx_past_day → is_fraud synthetic set. Correct and must remain intact.
    - train.csv – The 10-row training source used to fit model.pkl.
    - app.py – Flask app loading model.pkl and declaring GET /health + POST /predict. The /predict handler body is left as a TODO to author, and the app.run(...) bind port needs attention.

The end state must include:

    - curl http://localhost:8085/health returns {"status":"ok"} with HTTP 200.
    - curl -X POST http://localhost:8085/predict -H 'Content-Type: application/json' -d '{"amount":3200,"hour":23,"num_tx_past_day":5}' returns a JSON body with an is_fraud key.
    - The same POST with a low-amount daytime payload (e.g. {"amount":25.5,"hour":10,"num_tx_past_day":1}) returns a different is_fraud value – Confirming the endpoint actually reads the posted body rather than falling back to zeros.

The lab's port forwarding targets 8085; the running server must bind there to be reachable.

# Solution

Fix `/root/code/serving/app.py`:

```python
"""Flask fraud-detection prediction API.

Loads the pre-trained RandomForest at `/root/code/serving/model.pkl`
and exposes `/health` + `/predict` over HTTP.
"""

# Import libraries
import joblib                          # For loading/saving ML models
import numpy as np                     # For numerical computing (arrays, matrices)
from flask import Flask, jsonify, request  # Flask = web framework, jsonify = convert Python dicts to JSON, request = access HTTP request data

# --- MODEL LOADING ---
MODEL_PATH = "/root/code/serving/model.pkl"  # Path to the saved RandomForest model
MODEL = joblib.load(MODEL_PATH)  # Load the trained model into memory at startup
                                  # This happens once when the server starts, not on each request

# --- FLASK APP SETUP ---
app = Flask(__name__)  # Create a Flask web application instance
                       # __name__ tells Flask the app's module name


# --- HEALTH CHECK ENDPOINT ---
@app.route("/health")  # HTTP GET endpoint at /health (status monitoring)
def health():
    # Return a simple JSON response indicating the service is running
    return jsonify({"status": "ok"}), 200  # 200 = HTTP success code


# --- PREDICTION ENDPOINT ---
@app.route("/predict", methods=["POST"])  # HTTP POST endpoint at /predict (only accepts POST requests)
def predict():
    """
    Predicts whether a transaction is fraudulent.
    
    Accepts JSON body with transaction features:
      - amount: transaction amount in dollars (float)
      - hour: hour of day when transaction occurred (0-23)
      - num_tx_past_day: how many transactions the customer made in past day (int)
    
    Returns JSON with fraud prediction:
      - is_fraud: 1 = fraudulent, 0 = legitimate
    """
    
    # === STEP 1: Extract JSON body from the HTTP request ===
    data = request.get_json()  # Parse JSON from request body into Python dict
    
    # Validate that JSON was provided
    if not data:
        return jsonify({"error": "No JSON body provided"}), 400  # 400 = bad request
    
    # === STEP 2: Extract and validate features ===
    try:
        # Extract each feature from the JSON dict
        amount = float(data.get("amount"))              # Convert to float (handles 100, 25.5, etc.)
        hour = int(data.get("hour"))                    # Convert to integer (0-23)
        num_tx_past_day = int(data.get("num_tx_past_day"))  # Convert to integer
    except (TypeError, ValueError, KeyError) as e:
        # If any value is missing or can't be converted, return error
        return jsonify({"error": f"Invalid input: {str(e)}"}), 400
    
    # === STEP 3: Prepare features for the model ===
    # The model was trained on [[amount, hour, num_tx_past_day]] format
    # sklearn models expect 2D arrays: each row is a sample, each column is a feature
    features = np.array([[amount, hour, num_tx_past_day]])
    
    # === STEP 4: Make prediction ===
    # MODEL.predict() returns array of predictions (one per input row)
    # [0] gets the first (and only) prediction
    # int() converts from numpy integer to Python integer for JSON
    prediction = int(MODEL.predict(features)[0])  # Returns 0 or 1
    
    # === STEP 5: Return result as JSON ===
    return jsonify({"is_fraud": prediction}), 200  # 200 = HTTP success


# --- SERVER STARTUP ---
if __name__ == "__main__":  # Only run if this file is executed directly (not imported)
    # Start the Flask web server
    # host="0.0.0.0" = listen on all network interfaces (localhost, internal IP, etc.)
    # port=8085 = listen on port 8085 (where the lab forwards requests)
    app.run(host="0.0.0.0", port=8085)
```
